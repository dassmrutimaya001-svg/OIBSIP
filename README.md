# FocusFlow – Personal Productivity Dashboard

FocusFlow is a modern productivity dashboard built using React and JavaScript. It helps users organize daily tasks, manage priorities, track progress, and stay focused.

## Features

- Add, edit, and delete tasks
- Mark tasks as completed or pending
- Organize tasks by categories
- Set priorities and due dates
- Search and filter tasks
- Track productivity and task progress
- Light and dark themes
- Calendar and timer tools
- Save tasks and preferences using browser Local Storage

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Browser Local Storage

## Installation and Setup

1. Clone the repository:

   `git clone https://github.com/dassmrutimaya001-svg/OIBSIP.git`

2. Open the project folder:

   `cd OIBSIP`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

## Data Storage

FocusFlow uses browser Local Storage to save tasks and preferences on the same browser and device.
